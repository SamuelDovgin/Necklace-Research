## Integrity and provenance

- [manifest.json](manifest.json) records filenames, source location, archive date, byte counts, SHA-256 hashes, and the omitted duplicate.
- [SHA256SUMS](SHA256SUMS) supports verification from this directory with `shasum -a 256 -c SHA256SUMS`.
- Copies were checked against their originals after copying. This folder has been added to the local working tree; a remote backup requires committing and pushing it.
