# Necklace Research

Research, comparison data, and an RFQ dashboard for sourcing a lab-diamond drop necklace.

## Website

After GitHub Pages is enabled, the dashboard is published at:

https://samueldovgin.github.io/Necklace-Research/

GitHub Pages publishes from the repository root on `main`. Every push to `main` automatically republishes the site, and the root `index.html` opens the dashboard.

## Repository layout

- `necklace-rfq-package/dashboard/` — interactive research dashboard
- `necklace-rfq-package/docs/` — Markdown research and buying guides
- `necklace-rfq-package/data/` — supplier, listing, comparison, and RFQ data
- `necklace-rfq-package/assets/` — reference and listing evidence images
- `necklace-rfq-package/outputs/` — RFQ workbook

Open `necklace-rfq-package/dashboard/index.html` locally to use the dashboard without GitHub Pages.
